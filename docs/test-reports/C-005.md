# C-005 verification record

Baseline `g1-design-v2.0` at `9edbcd4b9a142d107df219bc64bd6730b39689cd`. Verified November 13, 2026. The durable checkpoint uses commit message `C-005 persist bounded project history` and includes this record with the implementation and state indexes.

## Delivered behavior

- A transport-neutral `ConversationRepository` defines canonical owner/project/conversation/message operations. Workspace application functions consume that port through one composition factory; the PostgreSQL adapter owns SQL and a substitute-repository test proves the seam.
- Project and conversation create/list/select behavior remains owner-scoped. Message append holds the conversation lock, allocates a unique increasing sequence, preserves exact Unicode bytes and source hashes, and returns stable ordered pages.
- `GET /v1/projects/{project_id}/history` implements bounded case-insensitive literal substring search for canonical message records in the selected owned project. Ordering is the frozen `(created_at, kind, resource_id)` keyset and `%`/`_` remain literal characters.
- Search cursors bind project, exact query digest, and keyset position and are authenticated with HMAC-SHA-256. The key is a dedicated durable random bootstrap secret of at least 32 bytes, separate from the login password. Modified, malformed, stale, and cross-project cursors fail with 400.
- Search results preserve stable project, conversation, message, optional run, excerpt, and timestamp source links. Message content can be reopened exactly after logout/login. Decision search is intentionally deferred until C-013 owns canonical decision records.
- nginx access logging uses path-only request data and excludes query strings, arguments, request URI, and Referer. A live canary verified that sensitive values in both the request query and Referer were absent from logs.
- The generated runtime OpenAPI snapshot includes the frozen project-history response surface and exactly matches the final running API.

## Requirements and limits

This verifies the C-005 portions of FR-001, FR-007, FR-008, NFR-002, NFR-013, P0-01, and P0-14. It does not claim decision search before C-013, synthetic retrieval, semantic memory, cross-project search, full release recovery, or P1/P2 behavior. C-012 owns the web chat surface; C-013 adds canonical decision history; C-015 owns final restart, restore, and browser release evidence.

No migration or frozen public contract changed. The implementation fills the already-frozen history route and repository seam, so no Change Request was required. Rollback restores the preceding application/proxy images; canonical rows remain unchanged. Existing issued search cursors are intentionally invalidated only if the dedicated signing key is rotated.
