## Delivered behavior

- `RunRepository` is now an explicit application/domain boundary for owner-scoped run
  reads, original reads, and manual-original import. The infrastructure adapter owns
  PostgreSQL locking and persistence details.
- Import locks the run row before the target row, verifies that the target belongs to
  the run and is manual/import-capable, then uses the database clock for the deadline
  decision. An official target cannot be replayed through the manual route.
- Original content is stored without normalization. Its digest is SHA-256 over the
  exact UTF-8 bytes, preserving leading/trailing whitespace, CRLF, and Unicode.
- Declared app and model provenance remains `user_declared` and acquisition remains
  `manual`. Resolved provider/model, elapsed time, token usage, and measured cost stay
  null. A missing declared model defaults to the frozen target label for compatibility.
- Exact replay compares content, family, app, and declared model, returns the stable
  response ID, and produces no duplicate audit event. A changed field conflicts.
- A new import at or after the deadline conflicts, while exact replay of an already
  committed result remains recoverable after expiry. Owner scoping hides foreign runs.
- The request rejects unknown fields and the 201 response uses the same canonical
  `OriginalDetails` contract as the response-list route.

## Requirements, integration, and limits

This verifies the C-008 portions of FR-002, FR-004, FR-005, FR-007, P0-05, and
P0-11: durable exact manual evidence, truthful user-declared provenance, owner scope,
deadline behavior, stable replay, and contract compatibility. The schema already
contained every required field, so no migration or Change Request was needed.

C-009 remains responsible for the durable queued/running/manual/synthesis/terminal
lifecycle and must enforce terminal/synthesis freeze across orchestration. Its
integration suite should also add an explicit synchronization barrier around the
concurrent import collision; the current thread-pool test exercises the database locks
but does not force a particular collision instant. Rollback restores the prior
application image and disables new imports while preserving all existing original and
audit evidence.
